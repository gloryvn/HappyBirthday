# Birthday Website
Mở `index.html` trực tiếp hoặc dùng Live Server (cần internet để tải font Google).

**Tuỳ chỉnh:** mọi nội dung nằm trong `js/config.js` (tên, số lần nhấn, lời chúc, lời nhắn cuối, ảnh + caption, nhạc, màu).
- Ảnh: bỏ file vào `assets/images/` và khai báo trong `CONFIG.photos` (ảnh thiếu sẽ hiện ô giữ chỗ).
- Nhạc: đặt `assets/audio/birthday-music.mp3` (tuỳ chọn). Âm thanh chạm bánh được tạo bằng WebAudio, không cần file.
- Lời nhắn cuối nên ngắn (~6–8 dòng) để vừa lá thư.
